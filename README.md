# Mallet
Mallet is a tool to perform loadtests. Its goal is to be able to maintain a target level of queries per second.
Currently only HTTP requests are supported.


# Request Generation
Requests are generated by an external process of your choice. Its only requirement is that it is executable and outputs the requests to use in [jsonl](https://jsonlines.org/) format. Example:

```
{"method": "POST", "query": "/api/", "body": "api body"}
{"method": "POST", "query": "/upload/", "body": "data", "unique": true}
{"method": "GET", "query": "/api/query?v=1"}
```

The above generates three requests, two of which will get used over and over again. The request with the key "unique" set to true will be used only once. If the process generating requests keeps writing to stdout then those requests will be used. If there are no new requests it will pull from a pool of cached requests it seen previously.
